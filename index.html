In Lua, type a module dot to see LÖVE API completions with preview support labels, or press Ctrl + Space. Hover a function or press F1 for its reference. Inline parameter names label literal arguments directly in your code, including the empty slot and unfinished literal while typing. Function completion adds parentheses and places the caret inside. They stay fixed while selecting or dragging and are never saved or copied as source text. Use the x: button or Ctrl + Shift + Space to show or hide them. The book button opens a searchable reference, including native-only APIs. The syntax result checks your code without running it; click an error to jump to its line. Target notes flag syntax outside the Lua 5.1 common subset. Native LÖVE compatibility still needs verification.

Edit main.lua, then Run or Restart. Click the game to give it keyboard focus. Try changing speed = 180.

Select an image or sound to open its central file tab. Image tabs preview and replace images. Click the filename in an image or sound tab to rename it; Enter or leaving the field saves, and Escape cancels. Sound tabs use one Play/Stop icon to preview the file or selection and open its containing Event, or explicitly add an unused file to an Event. Remove from Event keeps the file in Project. Remove file from Project removes it from Project and all containing Events while keeping the original file on your computer. X closes a tab or dialog; trash removes an item or module. Closing a tab keeps its item in Project. Project sound imports do not create an Event. Use Project’s + menu to create Events, import files or add a folder inside the selected category. Folders support inline renaming (F2), drag and drop within a category, and Move to folder in the options menu. Moving an item keeps its Lua name. Folder chevrons open branches; the panel icon hides the explorer. Shift-click selects a file range within a category; Ctrl/Cmd-click adds individual files. Right-click offers Rename, Make folder with selection and Remove for scripts, Events, images and sounds. Multiple selected items can be removed together. Remove Event is also available on Event Trigger; it keeps sound files in Project. Use Scripts + → New script to create another Lua file, or Import scripts to add existing .lua files. Each file has its own tab, cursor and undo history. The original entry script runs the game; modules run when required. Removing the entry disables Run; use New script to restore it. Renaming preserves file extensions and updates matching literal Lua calls; dynamic names need manual edits. A two-file demo project is available to open in the app. Load a module with local player = require("player") for player.lua. Return a table from the module. Filenames are case-sensitive at runtime. Project folders organize files without changing their module names. Literal require and file/Event references are updated across Lua files when renamed. Run/Restart always runs the entry, including when a module tab is active. Drag the space between panels to resize them. In an Event tab, press Space to play or stop the selected Event. Typing fields, parameter controls, menus and the game preview keep their own keyboard behavior. In Event graphs, drag empty space to pan and scroll to zoom. Drag nodes to arrange them; drag Repeat’s header to move its group.

In a sound tab, Play starts at the last waveform Hover position. Click the waveform while playing to seek; moving the pointer alone does not interrupt playback. A temporary selection always starts at its beginning. Drag to select, then resize with the framed grips at the middle of its edges. The timeline and file header supply timing information. Loop preview repeats the file or selection until Stop; changing the selection or Loop mode stops preview. Select Keep, Remove or Create sound from selection to commit an edit. A created sound opens separately, ready to rename; the source stays intact. Use Snap selection to quiet points to move each boundary by up to 5 ms toward a quieter point; audition the result to judge the seam.

Choose the Snippet mode icon in a recording’s header to collect sounds without leaving its waveform. Snippet mode shows the original recording, independent of its whole-file edits. Drag a range and activate the Create snippet icon inside the selection; choose a numbered region or its matching waveform thumbnail to edit its boundaries using source time. Full filenames are in tooltips and Rename. New snippets receive short Snippet 01-style filenames. Clear selection starts a new range. Gain, Normalize and draggable edge fades affect only the active snippet; Undo/Redo apply to that snippet’s audio edits. The active snippet’s icon tools sit above the waveform. Gain opens level controls; Rename opens the filename field, saved with Enter or by leaving the field. Escape closes these panels and returns focus. Fade curve icons toggle Linear/Equal power, with the current law in each tooltip. Rename the pool directly in the header. Use pool in Event copies up to 32 member sounds into a Sound; connect Randomizer there for Random, Shuffle or Sequence. Later pool additions are explicit, while edits to existing sounds remain shared with their Events. Pools appear as expandable entries under Project → Sounds and are included in project Save/Open and browser recovery. Save project creates a portable copy. Remove a pool before deleting its source recording; removing snippets also removes their Event references. Pool source files and members cannot be replaced. Original bytes are stored once; no new WAVs are rendered.

Add Ambient Loop from the Event module menu to replace Repeat with a continuous sound bed. Each instance fades in, holds at full level for a random time between Hold min and Hold max, then hands off using the fixed equal-power Crossfade. A new playhead stays at least Separation away from the outgoing source position, treating the file as a circle; very short files limit the effective separation to below half their edited length. Prepare a seamless loop in the sound editor: automatic end/start seam smoothing is deferred. Randomizer chooses one file on each Event trigger; that file is retained for its Ambient run. Pitch is held across both playheads, while connected volume ranges sample each instance. Connected Fade modules shape the whole Event. Stop prevents further handoffs and releases the current mix, using a connected Fade out or the Crossfade duration. Row audition still plays the file normally.

Enable Split and Swap to show two colored waveform regions. Move the split handle, then drag either region across the line or use the swap icon. Escape returns to selection. Show internal crossfades to expose join boundaries; drag a boundary to adjust the shared blend amount, up to 60 seconds and at most half of either neighboring section. Drag the center hand grip to move the join while preserving blend width and file duration. For Split and Swap this rolls the loop starting point; other joins use available source audio. The grip stops at source limits. Arrow keys move the focused grip by 1 ms; Shift moves 10 ms. Remove crossfades before other section edits. Show file fades to expose the fade-in/out handles. Drag a handle, or focus it and use arrow keys; Shift adjusts ten steps and Home/End goes to the limits. Setting a file fade to zero removes that edge. Values appear on the waveform during adjustment. Use the contextual Fade in, Fade out and Crossfade type menus to choose Linear or Equal power. The two file edges can use different types. Equal power can raise the peak where similar sounds overlap; check the peak annotation or Normalize. Fades preserve full-file coordinates during selection preview.

Double-click a parameter control to reset its default. Double-click its value readout, or focus the readout and press Enter, to type an exact value. Enter commits and Escape cancels; invalid or out-of-range values do not change the parameter. Grey slider fill shows the range below the current value. Volume sliders mark unity gain as 0 dB; Event volume is attenuation-only, while file and snippet gain also allow boost.

The File gain slider changes the whole edited file, independently of selection and Event volume. Normalize brings its sample peak to −1 dBFS; Reset gain returns to 0 dB. The peak annotation includes cuts, crossfades and file fades; normalization does not match perceived loudness. Edits affect every Event using this file and preserve the original audio. Undo/Redo covers this session; Restore Original also works after reopening. Save/Open and recovery retain edits. File-edge fades and joined playback need HTTPS and AudioWorklet support.

This is a UI prototype with a small Lua/LÖVE preview. Create Events with + in the project list. Each has one Event Trigger and Sound. Click an Event to open its tab; closing a tab keeps the Event. Event names must be unique. Lua can play Events with closed tabs. Different Events play together; retriggering the same Event restarts only that Event. A white dot in the Event list marks active playback. Switching Events stops editor playback; game-triggered playback continues. Add files to each Event’s Sound. Click a filename to replace that file; the triangle beside it auditions that file directly. Drag a file grip, or focus it and press Alt + Up/Down, to reorder the list. Click the Widgets icon at the top of the module menu to show or hide its icons. Hover or focus an icon for its tooltip. Add Randomizer from the file icon, Random Range from the dice, or Repeat from the replay icon. Drag Randomizer/Random Range to place them, or click to add. Randomizer selects Random, Shuffle or Sequence; connect its output to the socket on Sound’s left. Random permits immediate repeats. Shuffle uses each file once, then reshuffles. Sequence follows the displayed order, then wraps. Selection advances on each Event trigger and Repeat file pass; Shuffle and Sequence continue across triggers. Editing files, mode or connection resets that order. Without a connected Randomizer the first file plays. Row audition bypasses Randomizer, Random Range, Repeat and Shapes without advancing the order. Use the Repeat icon to wrap the Sound in a frame. Count sets total plays; Forever continues until Stop. Stop to change Repeat settings. Drag the Repeat header to move the group. Leaving Audio stops editor audition. Game audio also works with main.lua visible: use lyd.audio.play("jump") in love.keypressed. Download the tiny Space-key demo, or paste: function love.keypressed(key) if key == "space" then lyd.audio.play("jump") end end. Match the Event name exactly and load its Sound first. Optional settings apply only to that play: lyd.audio.play("jump", {volumeDb = -6, fadeIn = false, fadeOut = {speed = "fast", curve = "smooth"}}). Lua fade speed aliases: fast/medium/slow. Curve: straight/rounded/smooth. Add Fade from the module menu and connect it to a Sound or Output Volume socket. Curve snaps between three highlighted shapes; the turtle–rabbit Speed slider shows milliseconds on hover, focus or drag. Fade in can start once On trigger or on Each play, including every Repeat pass. Project Settings defines the duration limits. Omitted Lua fades inherit connected Fade modules; fade-out runs on Event Stop. Download the settings demo. Audio warnings appear in Console without stopping Game. Use lyd.audio.stop("ambiance") to stop that Event with its connected Fade out module; pending starts cancel immediately. Stop takes exactly one Event name. Download the ambiance + jump demo. Game Stop/Restart cuts all game-owned Events immediately. Each Event has its own live levels; combined levels add together. Export WAV in a sound tab downloads its file edits as mono/stereo PCM16 WAV at the playback sample rate. In Snippets, export the active snippet or all snippets as WAVs in a ZIP. File gain, trims, joins and file fades are included; Event randomization, pitch and playback fades stay in the project. Use Download project copy for an editable backup without the native Save picker. Original recordings stay in your project; audio game export remains deferred. Save/Open use a portable .lovely-ui file for recordings, including their original bytes; older .lovely-ui.json projects still open. Small projects may still save as JSON. Automatic recovery stays in this browser and is separate from Save. Audio must be decodable by this browser. Limits: 128 MiB per original audio file, 512 MiB of project assets, and 128 MiB of decoded audio including multi-file playback copies. Decode needs temporary memory, so these are admission limits, not a guarantee on every device. Cancel discards pending import work after the current native decode finishes. Export creates a .love game with your code and images.
